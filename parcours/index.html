QR code d'entrée (v4)

Le joueur scanne ce code à l'accueil : l'appli s'ouvre avec le parcours déjà chargé. Pour que ça marche, dépose le fichier exporté, avec le nom indiqué ci-dessous, dans le dossier scenarios/ à côté de l'appli.

Fichier attendu :

Supprime lieux, personnages, objets, objectifs, images et réglages, et remet la progression à zéro. Le nom du joueur est conservé. Exporte d'abord si tu veux garder ce parcours.

Outils de test

Tout ce que l'appli a fait juste avant un souci : erreurs, écritures refusées, temps de chargement. Le journal survit à un rechargement.

Statistiques (v7)
